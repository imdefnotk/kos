K.OS launcher music
===================

K.OS Home plays kos-idle-ambient.ogg (in this folder) as its home screen music:
a calm 32 second loop. If the file is missing, the launcher makes its own
generated music instead.

To use other music, put a file here named:

  ambient.mp3   (or ambient.ogg)

It is used before kos-idle-ambient.ogg and loops on the home screen, at the
level chosen in Ayarlar, Ses. Only use music you own or have a license for.
